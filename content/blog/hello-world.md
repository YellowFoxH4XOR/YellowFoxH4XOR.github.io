Welcome to the new site. I rebuilt it on **Next.js** so that adding a post is as
simple as pushing a markdown file to GitHub — the site rebuilds itself and the
post goes live.

## Why write?

Writing forces clarity. If I can't explain a system simply, I probably don't
understand it well enough yet. So this is partly a notebook and partly an
archive of things I've figured out.

## What to expect

- Notes on backend and systems engineering
- The occasional deep dive into something I broke and fixed
- Books and ideas worth sharing

> The best way to learn is to build, break, and write it down.
